⚙️ Getting Started

Follow these steps to run the portfolio locally.

Prerequisites

Make sure you have installed:

- "Node.js" (https://nodejs.org/) — preferably a supported LTS release
- npm, included with Node.js
- Git

Installation

1. Clone the repository

git clone https://github.com/adyashitbiswal-rgb/adyashit-robotic-portfolio-main.git

2. Navigate to the project directory

cd adyashit-robotic-portfolio-main

3. Install dependencies

npm install

4. Start the development server

npm run dev

5. Open the local website

Open the local URL printed in your terminal, typically:

http://localhost:3000

The actual port may differ depending on the project's configuration.
